## 1. 底辺の二重帯: 原因と直し方

原因は 9スライスの縦軸タイリングだった。halftone 素材は
create_frame_style で両軸 AXIS_STRETCH_MODE_TILE。会話窓（1056×190）の
中央帯の destination 高（154px）がソース帯（256px）より短いと、TILE は
帯を途中で切り捨て、底辺ストリップ（ソース行 286〜316）との間で斜行が
slope 0.25 × スキップ行数だけ跳ぶ。実測: 本体は y460〜561 で斜行どおり
漸進、その下 y562〜575 に左端が +26px 跳んだ赤帯が分離して描かれていた
（単独パネル再現でもモデル予測 +25.5px と一致）。形状の実底辺行
（184〜286）は描かれていなかった。B-1318 の中央＝半タイルスライス自体は
正しく、背の高いパネルで TILE_FIT に出る段差（B-1315 の既知制限）と同根。

直し方: skew 枠では縦軸を AXIS_STRETCH_MODE_STRETCH に上書きする
（create_frame_style、素材分岐の後）。中央帯がソース帯全体を写すため
斜行が切れず、底辺ストリップと 1本につながる。横軸は従来どおり
（halftone は TILE でドット pitch を保ち、他素材は TILE_FIT）。副作用
として、背の高い skew パネル（menu 等）の側ストリップのタイリング段差
（B-1315 の既知制限）も撮影上は解消した。

性質テスト（tests/scene/test_uzu_ui.cpp）: StyleBoxTexture の軸モードを
再現する 9スライス描画シミュレーションで、persona 枠を 1056×190 /
1056×120 / 700×600 に描き、alpha>0.98 の左右端の行間ステップ最大 ≤3 を
要求。縦軸モードが STRETCH であることも固定。あわせて B-1315 の
スライダーテストにあった「persona 枠の縦軸は TILE」の固定を STRETCH に
更新（本項目の意図的な変更。横軸 TILE の固定は不変）。

## 2. グリントの滲み: クリップ方法

WORLD_FRAME_SHADER の mode 1 グリントは stylebox テクスチャ全体に mix
されていた。枠テクスチャには落影（halftone の hard shadow は alpha
0.85・RGB 黒）も同居するため、影まで白く持ち上がり、窓の下に白いぼやけ
として漏れていた。帯域も幅 110px の柔らかい帯で、静止画では汚れに見えた。

直し方（uzu_ui.cpp の WORLD_FRAME_SHADER と create_world_material）:
- uniform `mask_lo` / `mask_hi` を追加し、グリント係数を
  `smoothstep(mask_lo, mask_hi, COLOR.a)` で枠本体にクリップ。落影や
  ガラス下の素通し部分には光らない。
- 帯域を smoothstep(0,14) × (1−smoothstep(14,54)) に狭小化し、persona
  の strength を 0.4 → 0.30 に。
- DECOR テーブルにマスク列を追加: fantasy/wafu/horror/pixel/persona は
  0.90/0.99（本体 alpha ≈1.0、影 0.85 を除外）、sf は 0.60/0.84（ガラス
  本体 ≈0.86、soft shadow ≤0.5 を除外）。

性質テスト: 全世界観で mask_lo > 0.5 かつ hi > lo かつ hi ≤ 1.0、persona
は lo > 0.85・hi < 1.0、sf は hi < 0.86、シェーダコードに
`smoothstep(mask_lo, mask_hi, c.a)` を含むことを固定。

## 3. 背景構図: 実装方法

キットに手続き生成の背景部品を追加した（uzu_ui.h/.cpp、
doc/classes/UZUUI.xml にバインド）:

- `draw_backdrop(style)`: スタイル辞書から 1152×648 の Image を生成。
  キー: size / base / mottle（fbm の乗算式まだら）/ band（平行四辺形の
  色帯、斜行は skew と同じ slope）/ band_y / band_h / band_halftone /
  band_under（帯の下敷き色面）/ band_under_h / line（帯の上辺の白線）/
  glow / glow_pos / glow_strength / vignette / seed。
- `get_backdrop_options(world)`: 世界観プリセット。persona = 黒地
  #0b0508 に赤 #e60012 のハーフトーン斜帯（y 0.60、h 118）＋黒の下敷き
  ＋白線＋vignette 0.35。wafu = #17120d のまだら壁＋暖色グロー
  （#3a2812、画面下寄り）＋vignette 0.6。fantasy/sf/horror/pixel にも
  構図あり（pixel は紺の帯＋金の線）。
- `make_backdrop(world)`: TextureRect（FULL_RECT、COVERED、マウス無視）
  を返す。見本 main.gd はこれを背景として敷く。

性質テスト: 全世界観で 1152×648・輝度 sd > 0.002（単色は 0。暗い世界観
horror/pixel の実測 0.0036〜0.005 に合わせた水準）、vignette の角落ちを
同一スタイルから vignette を消した版との厳密比較で固定、persona の
赤画素 > 2000・wafu の赤 = 0、未知の世界観は空辞書/nullptr、
make_backdrop の mouse_filter が IGNORE。
