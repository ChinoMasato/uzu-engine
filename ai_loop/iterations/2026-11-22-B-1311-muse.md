# B-1311 枠テクスチャの高品質化（2026-11-22、Muse subagent、agent/b-1311-muse）

監査（ui-quality-audit-20261122.md）の欠陥1（装飾ドットの格子漏れ）と欠陥2（質感が単層）への対応。

## 1. 装飾漏れの原因特定と構造修正（実バグ）

**原因**: `draw_frame` の 9スライス角マージンは `corner = MAX(radius, bw*2, orn) + 2` で、
装飾の大きさ orn（10px）しか見ていなかった。しかし装飾の描画位置は枠端から
`bw + 3` px 内側を起点に orn px の範囲（和風: 6〜16px）で、到達端は角マージンの
確保量（12px）を 4px 超えていた。はみ出した部分は 9スライスの**縁ストリップ**
（上下左右のタイル繰り返し領域）に落ち、TILE_FIT で等間隔に複写されて
パネル全面の辺にドットが並んでいた。

**再現（修正前バイナリ、和風枠を UZUUI.draw_frame で描画し朱色画素を数えた）**:
- wafu（diamonds）: size 164 / margin 18 / tile 128、縁ストリップ内 16px、中央タイル内 0px
- fantasy（brackets）: 縁ストリップ内 64px
- 実画面（before/wafu_world_ui.png）: 会話窓とステータス窓の上下辺に等間隔の赤ドット

**修正**: 角の確保量を装飾の到達端まで広げた。
`orn_extent = bw + 3*scale + orn`、`corner = MAX(MAX(radius, bw*2), orn_extent) + 2*scale + skew分`。
装飾は角マージン内に完全に収まり、タイル領域へは一切入らない（構造で保証）。

**修正後の実測**: wafu 縁ストリップ 0px（角内 96px）、fantasy 縁ストリップ 0px（角内 144px）。
実画面（after/wafu_world_ui.png）でも辺のドットが消え、四隅にのみダイヤが出る。

## 2. 素材生成の高品質化（fbm＋ドメインワープ、タイル 256）

- `tile_noise`（単一オクターブ値ノイズ）を廃し、タイル周期を厳密に保つ
  `value_noise`（格子がタイル内のセル数で wrap）＋ `fbm_noise`（オクターブごとに
  セル数を倍化、全て整数なので周期は厳密にタイルと一致）＋ `fbm_warped`
  （fbm 場でサンプル点をずらすドメインワープ。ワープ場も同周期なので継ぎ目なし）。
- FRAME_TILE は 128 → **256**。
- 全素材を「大きなムラ＋中間の質感＋微細グレイン」の多層構成に載せ替え:
  羊皮紙（swell fbm＋ワープ drift＋繊維＋グレイン、低コントラスト維持、焦げ端は従来どおり）、
  木（ワープで曲げた年輪＋mottle＋グレイン）、金属（異方性 fbm の刷毛目＋mottle＋グレイン）、
  石（ワープ fbm＋等高線状のひび）、ガラス（タイルを割り切る周期の走査線＋sheen）、
  網点（セルがタイルを割り切るグリッド、半径の増大もタイル内で wrap）、
  汚れ（ワープ fbm＋等高線状の傷）。
- ついでに旧実装の潜在的な継ぎ目も解消: 旧 metal の `tile_noise(x*0.25, ...)` は
  周期がタイルの4倍で継ぎ目があった。旧 halftone（セル6px）・glass（3px周期）・
  grime（fposmod 23）もタイルを割り切らず継ぎ目があった。

## 3. 生成解像度スケール

- スタイルに `"scale"`（1 または 2、既定 1）を追加。全ての長さ（タイル・角丸・
  枠幅・影・装飾・素材の周期）を scale 倍で生成する。`create_frame_style` の
  マージン・展開マージンも追随。和風で実測: scale 1 = 304px／マージン 24、
  scale 2 = 608px／マージン 48（ちょうど2倍）。
