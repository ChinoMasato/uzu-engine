## 設計

### タイプスケール（比率 1.25 の根拠）

5段 display／title／heading／body／caption を、基準サイズ（テーマの `font_size`）からの
モジュラースケールで定義した。比率は **1.25（長三度、古典的なタイプスケールの標準値）**。

- 1.125 では 20px 前後のゲーム UI サイズで段差が知覚しにくく、階層にならない。
- 1.5 では display が基準の約3.4倍になり、HUD や会話窓に収まらない。
- 1.25 なら基準18で 14／18／23／28／35 と、実用域で一段ごとに明確に効く。

| step | 倍率 | 基準18 | 基準19（世界観） | 基準16（pixel） |
|---|---|---|---|---|
| display | 1.25³ = 1.953125 | 35 | 37 | 31 |
| title | 1.25² = 1.5625 | 28 | 30 | 25 |
| heading | 1.25 | 23 | 24 | 20 |
| body | 1.0 | 18 | 19 | 16 |
| caption | 1/1.25 = 0.8 | 14 | 15 | 13 |

### 段ごとの付随値

- **行間（line_spacing）**: 小さい文字ほど広く、大きい文字ほど詰める。本文・注釈 = サイズ×0.30、
  見出し = ×0.20、title = ×0.15、display = ×0.12。
- **字間（letter_spacing、px）**: 一目で読む段だけにトラッキング。display = サイズ×0.05、
  title = ×0.04、heading = ×0.02、caption = ×0.05（小サイズの可読性補助）、body = 0。
  実装は FontVariation の SPACING_GLYPH（テーマのフォント、無指定時は ThemeDB の
  フォールバックフォントを包む）。この版の Godot では `set_spacing(SPACING_GLYPH, px)` 形式。
- **装飾プリセット（縁取り・影）**: display = 縁取り サイズ×0.10（上限6）＋影 (2,3)、
  title = 縁取り ×0.07（上限4）＋影 (1,2)、heading = 影 (0,1) のみ、body／caption = なし。
  色はテーマの文字色から導く「 shade」: 明るい文字には黒系、暗い文字には白系
  （不透明度 display 0.85／title 0.8、影は heading 0.3／他 0.42）。世界観ごとに
  アクセント色へ寄せはしない（文字色とのコントラスト保証を優先）。
- **caption の文字色**は文字色の不透明度 0.7（注釈は一段引く）。

### 置き場所

- 各段は Label のタイプバリエーション `UZUDisplayLabel` 等として、create_theme と
  create_world_theme（前者経由）の両方のテーマに登録される。テーマのメタ
  `uzu_type_scale` にスケール辞書そのものが入り、道具側が数値を読み戻せる。
- 公開 API の追加は2つだけ: `UZUUI.get_type_scale(base_size)`（スケール辞書）と
  `UZUUI.make_label(text, step)`（段名でラベルを作る適用ヘルパー。不明な段は body）。
- 世界観テーマには追加で `UZURibbonLabel`（title 段のサイズ＋名札と同じコントラスト色）を
  登録し、make_ribbon が使う。

### 後方互換

- 既存の単一 `font_size` オプションはそのまま「スケールの基準」になる。既存の呼び出し・
  JSON は壊れない（make_dialog の題字 22px 固定 → title 段、make_item_slot の個数 14px 固定 →
  caption 段、make_ribbon の 22px 固定 → UZURibbonLabel へ移行。会話窓の本文とダイアログ本文は
  body 段を指定）。
- JSON（ui_tool.gd）の Label に `"text_style": "display"` 等を追加。数値 `font_size` と
  併記した場合は数値が勝つ（従来どおり override が後勝ち）。
