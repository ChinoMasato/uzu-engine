# B-1322 品質の次の一段——グラデーション／ライティング／エフェクト（Muse、2026-11-23）

オーナー FB「だいぶ良くなってきたが、まだクオリティは上がるはず」「グラデーションや
ライティングやエフェクト」への回答。絵面の豊かさを作る3要素を、キットの共通機構として
投入し、persona 見本（2D）と 3D 試行の両方に適用した。before/after 並置は
`ai_loop/look_samples/b1322/`（persona 5画面＋3D title/menu）。

## (1) グラデーション拡張（scene/gui/uzu_ui.cpp）

- `gradient_ramp(style, prefix, base)`: prefix は `gradient_`（frame 本体）と
  `band_gradient_`（backdrop の帯）。`<prefix>stops` に色の Array があれば
  [base]＋stops の等間隔ランプ、無ければ従来の `<prefix>to` 2点。テクスチャ生成は
  ランプをサンプルする形に一般化（2点はランプの特殊形として互換維持）。
- 放射: `gradient_dir: "radial"` ＋ `gradient_center`（0..1、既定中央）＋
  `gradient_radius`（既定 0.75、長辺比）。radial は stylebox の両軸 STRETCH
  （TILE だと放射が崩れる）。halftone の横 TILE は据え置き（モアレ回避、B-1321 の知見）。
- persona 適用: frame は 3点ランプ #e60012→#c40010→#8f000c（下へ深く）、
  backdrop の地は radial（中心 (0.30, 0.16)、#160409→#030204）で左上に光の芯、
  帯は 3点ランプ #f00014→#a80010。反転バー等のベタは据え置き。

## (2) ライティング

- 2D: WORLD_FRAME_SHADER に uniform 3つを追加し、すべて B-1319 の枠本体マスクで
  クリップ（二重実装なし）。光源方向は左上に統一。
  - `sweep`: 斜行する広い光の帯がゆっくり横切る（周期 9s、帯は柔らかい）。
  - `rim`: TEXTURE のアルファ勾配（±6px）から左上光のリムを合成。
  - `bloom`: 輝度 0.72 以上を持ち上げる擬似ブルーム。
  Decor 表: persona 0.30/0.45/0.22、fantasy 0.10/0.30/0.10、wafu 0.06/0.18/0.05、
  sf 0/0.25/0.30、horror 0/0.08/0、pixel 全0（世界観ごとに濃さを持たせた）。
- 3D（b1321）: レーキ光（横切る SpotLight3D）が位置ドリフト＋エネルギー呼吸し、
  フォーカス着地でフレア（0.7·exp(-3Δt)）。太陽光も ±3° のドリフト。カメラリグに
  基底角（y −1.6°／x 1.2°）を持たせ、わずかに見上げる構図に。

## (3) エフェクト（b1315/project/fx_layer.gd 新規）

決定論的 LCG の自前描画レイヤー（パーティクルノードの乱数に依存しない）。
- 塵モート: 常時漂う微粒子（persona 26個・白、wafu 12個・暖色）を backdrop 直後に配置。
- burst: フォーカス着地でボタンの先端にスパークル（0.45s）。
- flash: 押下時に画面へ白フラッシュ（0.30s、薄く）。
- slash: 画面遷移で斜行 streak 3本（0.38s）。
main.gd が全 Button に focus_entered／pressed を配線（_goto の再構築後も再配線）。

## 残件3点への対応

- メニューバーの文字: ui_tool に共通キー `letter_spacing` を追加（FontVariation で
  テーマフォントへ適用）。persona title の Button は 27px／字間 −1、menu・settings は
  24px／−1。バーに対して文字が細い問題は解消（比較画像 persona_title/menu 参照）。
- 会話画面の空白: 透かし「CHAPTER」を 130px・alpha 0.13 に拡大配置、第2リングと
  slash の deco を追加。密度は上がったが、キャプション「CHAPTER 1」が radial で
  明るくなった地にやや洗われる（判読可、追っていない）。
- 3D 構図: 透かし「MIDNIGHT」を奥 (z −1.8)・150px・alpha 0.16 へ引いてバーとの
  干渉を解消。バーの Label3D は 30→34px。カメラ基底角で見上げ構図に。

## 残り・所感

- sweep は静止画では帯の位置でしか見えず、動画で初めて効く。強さ 0.30 は
  「気づくが邪魔でない」境目として置いた。

  フォーカスフレアの方が効果が読みやすい。

  色数が増えた分）。上限 0.35 に対して余裕はあるが、ランプを増やすほど
  シート性は下がるトレードオフとして記録する。
