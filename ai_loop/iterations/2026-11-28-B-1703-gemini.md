# B-1703 ライセンス台帳と同梱ガード — Gemini 4 (AI Studio) 実装・リード統合 (2026-11-28)

担当: Gemini 4 Hydrogen（AI Studio ブラウザ経由）。AI Studio 経路の4例目。

## 成果物（ai_loop/lumina_bridge.py への拡張）
- **クレジット台帳**: 配置のたびに配置先へ `uzu_sfx_credits.json`（形式 uzu-sfx-credits/1）を生成し、既存台帳へマージ（event 単位で upsert）。壊れた台帳は上書きせず警告に回す。結果 JSON に manifest の res:// パスを追加。
- **ライセンス警告**: 結果 JSON の warnings に、CC0／Public Domain／PD 以外のライセンス（表示義務つき等）とクレジット不明の音を、event と license つきで列挙する。警告は ok を変えない。
- **同梱ガード**: `check_export(dir)` と CLI `--check-export`。ルールは lumina-catalog（内容で判定）／lumina-recipes（recipes 配下の .ts）／lumina-skill-file（記録・台本ファイル）の3種をデータ駆動で定義。

## リードの修正（2点）
1. **カタログ判定の実物対応**: 生成コードは catalog.json の dict 形を "recipes" キーで判定していたが、実物の Lumina catalog.json は項目を **"sounds"** キーに持つ（{"schemaVersion":1, "count":2882, "sounds":[...]}）。このままだと本物のバンクを取りこぼすため、判定キーに "sounds" を追加した。原因は指示書に実カタログの構造を書いていなかったこと（指示書側の情報不足）。
2. 配置が0件のとき結果の manifest を実在しないパスではなく null にした（AI 向け出力の正確さのため）。
