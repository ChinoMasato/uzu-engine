## ゴールと構造の読み

オーナー指示「競馬ゲームやシミュレーションゲームで使えそうなUIも
作って欲しい」。正は ChatGPT 生成リファレンス4枚（~/workspace/aaa-refs/、
第二弾）。このジャンルの文法はアクション系と逆で、**主役は表とパネル**。
アートは背景と詳細パネルの写真に回り、密度は「バー＋数値＋アイコン＋
適性記号」で作る。共通部品は 上部ステータスチップ／タブ／メイン
テーブル＋右詳細パネル／下部コマンドボタン。

見本プロジェクト（b1315/project）に世界観を2つ新設し、3画面を追加:
- **racing**（深緑 #17452c ＋金 #d9a441、metal 枠・brackets 装飾）
  - `stable` 厩舎画面: 馬一覧8行（顔サムネイル／馬名／年齢／性別／
    スピード・スタミナのバー＋数値／調子フェイス／芝・ダート適性
    ◎○△×／成長型／厩舎）＋選択行ハイライト＋右詳細パネル＋
    所持金・日付チップ＋タブ5＋コマンド6。
  - `entries` 出馬表: レースヘッダ帯（中山11R・春風ステークス・
    芝1800m・晴・馬場良）＋12行（枠色チップ／馬番／馬名／性齢／
    騎手／負担重量／オッズ右寄せ／人気）＋右詳細パネル。
- **sim**（濃紺 #1c3252 ＋金、metal 枠・rivets 装飾）
  - `main` 経営シム: 全面マップ＋上部資源バー（チップ7、増減表示
    付き）＋右カレンダー（第42週・今日ハイライト・今週の予定）＋
    左下タスクリスト（チェック＋進捗数）＋施設ラベル3＋下部
    コマンド6と大きな「次の週へ」。

行の選択で詳細パネルが連動する（行の pressed と focus_entered の
両方をドライバ main.gd の _wire_data が配線）。騎手名はリファレンス
に実在名が含まれていたため、見本では架空名に差し替えた。馬名は
構造比較のためリファレンスの架空名を流用。

## キット部品化（scene/gui/uzu_ui.{h,cpp}、doc/classes/UZUUI.xml）

テーマのバリエーションで世界観に従う C++ 部品として一般化した
（『スターホース牧場』等の実プロジェクトへの流用が目的）:
- `make_stat_bar(caption, value, max, options)`: 見出し＋滑らかな
  バー＋数値。バリエーション `UZUStatBar`。options: caption_width /
  value_width / bar_height / fill（このバーだけの色上書き）。
- `make_status_chip(caption, value, options)`: 錠剤型チップ。
  バリエーション `UZUChip`（見出しは `UZUChipCaption`＝アクセント色）。
  options: delta（増減表示）/ delta_color。
- `make_data_table(columns, rows, options)`: ヘッダ帯
  （`UZUTableHeader`）＋トグル行（`UZUTableRow`、単一 ButtonGroup で
  常に1行だけ選択）。セル種別: 文字列／{"text","color","align"}／
  {"bar","max","fill"}（ミニバー）／{"face" 0..4,"text"}（調子
  フェイス＋語）／{"image"}（Texture2D）／{"chip" 色,"text"}（枠色
  チップ）。行は "row_data" メタと "row_index" メタを持つ。
  **幅の規則**: 列幅はセルの最小幅で、行はほかに両端マージン8pxと
  セル間 separation 4px を使う（uzu_ui.h のコメントに明記。初回撮影で
  合計幅だけ見て最終列が切れたため、規則として残した）。
- `select_table_row(table, index)`: 行を押下状態にして返す。
- `make_detail_panel(options)` / `set_detail_panel(panel, data)`:
  題＋ポートレート＋キー値行（Rows）＋能力バー（Bars）。set で
  中身を差し替える。options: portrait_height / key_width /
  bar_caption_width / data（初期データ）。
- 調子フェイスは `condition_face_image` が毎回描く 28×28 アイコン
  （関数 static な Ref 保持は終了時クラッシュの前例があるため
  キャッシュしない）。レベルで口の弧と顔色が変わる。

ui_tool.gd には JSON 型 `StatBar` / `Chip` / `DataTable` /
`DetailPanel` を追加（DataTable のセル "image" と DetailPanel の
"data.portrait" は res:// パス文字列で書け、ビルド時にテクスチャへ
解決する）。世界観の追加に伴い test_uzu_ui.cpp の世界数を 6→8 に
更新し、B-1326 のテストケース（両世界観のプリセット＋部品の構造・
選択連動・詳細の差し替え）を追加した。

モーションは両世界観とも overshoot 0・duration 0.3/0.35
（データ画面では行が跳ねないことが読みやすさの一部）。

## 素材（ai_loop/look_samples/b1326/prep_assets.py、一回限りの加工）

リファレンス3枚は UI 込みの完成絵なので、背景アートは切り取り・
リフレームで作った（見本としての割り切り）:
- `stable_pano.jpg`: 厩舎リファレンスのヘッダ裏に走る牧場パノラマ
  帯 (0,95)-(1672,215) を切り取り、画面上部の帯として使用。
- `entries_pano.jpg`: 出馬表リファレンス上部の空・スタンド帯
  (0,70)-(1672,150)。
- `sim_map.jpg`: 経営シムのマップ中央 (350,170)-(1374,776) を
  16:9 にリフレームした、唯一きれいに切れる全面アート。切り取り
  位置は UI 残片が自画面のパネル下に隠れるよう選んだ（左下の
  タスク残片→タスクパネル下、右上の研究所ラベル→カレンダー下、
  左上の吹き出し尻尾→上部バー下）。焼き込み済みの施設ラベル4つ
  （製鉄所・製材所・倉庫・港）は開けた地面に残りマップラベル
  として読める。自前のラベルは焼き込みのない施設（王宮・市場・
  農園）に置いた。
- `horse_cut.png` / `horse_face.png`: 馬アセットを B-1324 の
  テクスチャ分離 flood fill（背景色距離<30 かつ輝度<52 かつ局所
  std<2.2 の端接続成分）で切り抜き。頭部は切り抜き座標で
  x<42%・y<60% のアルファ塊の bbox（頭＋首＋たてがみ、494×600）。
- `face_0..7.png`: 顔クロップの色調バリエーション8種（96×96）。
  芦毛（ホワイトオーシャン用）は輝度経由、黒毛は深い乗算。
- `game_font_jp.ttf`: 既存 game_font.ttf は 614 グリフのサブセット
  で本画面の漢字の大半（芝・牡・牝・歳・週・億・円・枠・騎・厩 等）
  が無く、従来画面も撮影時のシステムフォールバックで埋まって
  いただけだった（README 規約違反の状態）。Noto Sans CJK JP
  （TTC face 0）から拡張サブセット（747 グリフ）を生成し、本3画面
  の spec だけが参照する（既存画面には触らない）。収集字種は
  全 spec＋main.gd の走査＋計画文字列で、生成後に使用文字列の
  欠けゼロを確認した。

撮影は見本の設計空間 1152×648 に合わせ、レイアウトは当初設計
（1600×900）から ×0.72 で換算した。チップ等のテーマ由来サイズは
換算対象外（本文16px のまま）で、チップ幅は文字列から実寸で決めた。

## リファレンスとの差分（残った点）

- 背景アートは全面ではなく帯＋マップのみ（リファレンス完成絵
  からの切り取りの限界。上記の割り切りを参照）。
- 厩舎画面のタブは選択状態の見た目が均一（リファレンスは選択
  タブが発光）。行選択が主役のため見送った。
- 馬の顔サムネイルは1頭の色調バリエーション（リファレンスは
  頭ごとに別個体）。詳細ポートレートは個体感がある。
- リファレンスの表は行間罫線が強いが、本見本は行の地色差＋
  選択ハイライトで代替した（キットの行スタイルの範囲）。
- sim マップにはリファレンスの焼き込みラベルと自前ラベルが
  混在する（様式は揃えてある）。
