# B-1323 後半 sf／pixel 見本（Muse (subagent)、2026-11-23）

B-1323 の後半分担。fantasy／horror は別エージェント（agent/b-1323a）が並行担当し、
本記録は sf と pixel の2世界観のみ。見本は `ai_loop/look_samples/b1323/{sf,pixel}/`
（5画面＋モーション動画15秒）、specs は `b1315/project/specs/{sf,pixel}_*.json`（新規10本）。

## sf の味付け（題材「ミッドナイト・プロトコル」）

- ロゴはシアンのゴースト影（#38e1ff・(7,7)）＋濃紺の縁、英字キャプション
  「MIDNIGHT PROTOCOL」字間3。ボタンは水平・無回転のガラス chamfer 3本。
- 背景は放射グラデーションのホログラム場（中心 (0.5, 0.30)）＋地平の帯と
  シアンの罫線が画面を横切り、細リングと十字スパークル。透かしは
  PROTOCOL／PAUSE／CONFIG／STATUS／SIGNAL（いずれも水平、回転なし）。
- メニュー／設定は見出し＋英字キャプション＋シアン罫（Color 2px）の
  ホログラムパネル調。ゲージは HP／EN のセグメント表示、HUD スロットは
  コア／キー／セル。会話はリボン「第壱章　真夜中のステーション」、
  話者「不明な信号」、本文は persona と同じ筋（欠片→コア、図書館→ステーション）。
- fx の塵は 18個・シアン寄り（Color(0.55, 0.92, 1.0, 0.40)）、burst はシアン。
  モーションは世界観表の expo のまま（キレの良さは表側の既定）。

## pixel の味付け（題材「まよなかクエスト」）

- 全かなレトロ文面（話者「なぞの こえ」等）。ロゴはアンバーのオフセット影
  （#f4b41a・(6,6)）＋濃紺の縁、「MIDNIGHT QUEST」24px 字間2。
- パレットはテーマ既定の限定色のみ（紺ボタン／アンバー／緑ゲージ／白）。
  背景はベタ＋段調：地平の帯に加え遠景の帯（band2・#141830・y0.30・h28）を
  追加し、どちらも slope 0（水平）を明示。透かし・太バー（h10）・太リング
  （幅7–8）の deco は main.gd の pixel 分岐で太くベタに寄せた。
- 撮影は 1152×648 を ÷2 → ×2 のニアレストで再構成し、ドットが立つ解像度に
  した（動画も同フィルタ）。ゲージラベル等の細い字はこの過程でやや痩せる
  （包含・可読は確保、レトロ表現の範囲として許容）。
- フォント規約との関係: 撮影フォントは規約どおりプロジェクト内蔵の
  チェック済み JP フォント（res://art/game_font.ttf）をそのまま使い、
  システムフォールバックはしていない。ドット表現はフォント差し替えでは
  なく撮影後の解像度処理で作った（字形そのものはフォント由来）。

  mask 0.60–0.84 はテスト固定のため不変）。
- sf backdrop: 地を放射（#051824→#020507、中心 (0.5, 0.30)）に深め、
  帯 #06222e（y0.80・h54・slope 0）、罫 #38e1ff、星 7・#7ff0ff、vignette 0.4。

  他世界観への影響はない。適用後 sf_talk は rest／peak とも pass。
